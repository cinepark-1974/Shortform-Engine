## 개요

Shortform Engine은 **1~2분 × 80~100화** 세로형(9:16) 숏폼 드라마 시나리오를  
기획부터 집필까지 하나의 엔진 안에서 완결하는 양산형 집필 도구입니다.

- 1편(100화) 시나리오를 **3~5일**에 완성
- **매주 1편** 생산 가능한 시스템
- 드라마박스 / 비글루 / 탑릴스 등 글로벌 숏폼 플랫폼 유통 기준 충족
- 기존 글(소설/시나리오/웹툰/실화)을 막장 숏폼으로 자동 변환

| 항목 | 값 |
|------|------|
| 에피소드 길이 | 1~2분 (세로 9:16) |
| 총 에피소드 | 80~100화 |

| 총 클릭 수 | **22회** (컨셉 1 + 아크 1 + 집필 20) |
| AI 모델 | claude-sonnet-4-6 (속도 우선) |

## 기능

### TAB 1 — 새 숏폼 만들기

| 단계 | 내용 |
|------|------|
| **공통 설정** | 작품 톤(조용한 톤 / 독한 톤) · 첫 자막 형식(배지형 / 문장형 / 없음) — 탭 위에서 한 번 고르면 모든 단계에 적용 |
| **STEP 1 컨셉** | 막장 공식 4종 선택 → 주인공/악역/비밀 입력 → 컨셉 자동 생성 |
| **STEP 2 아크** | 100화 시즌 아크 설계 → EP별 1줄 요약 + 클리프행어 유형 + 과금 포인트 |
| **STEP 3 집필** | 블록 20개 × 5화 = 100화 대본 스트리밍 집필 |
| **STEP 4 다운로드** | 전체 TXT + 아크 CSV 저장 |

### TAB 2 — 기존 글 → 숏폼 변환

텍스트를 붙여넣으면:
- 원본 분석 (핵심 갈등 / 활용 가능한 요소 / 숏폼에 안 맞는 이유)
- 막장 공식으로 변환 전략 설계
- 파일럿 EP1 대본 자동 생성
- "이 컨셉으로 100화 만들기" 버튼으로 STEP 1 파이프라인 연결

## 막장 공식 4종

| 공식 | 설명 | 과금 포인트 |
|------|------|-------------|
| **재벌 복수** | 가난한 여주 → 재벌가 → 학대 → 비밀 → 역전 | EP 16: 출생의 비밀 |
| **능력 각성** | 무시당하는 주인공 → 1화에 능력 발현 → 하나씩 꺾기 | EP 16: 능력의 주인 공개 |
| **귀환 / 재회** | 5년 후 돌아온 사람 + 아이의 정체 | EP 16: 아이 아버지 폭로 |
| **복수극** | 배신당함 → 새 정체 → 하나씩 무너뜨리기 | EP 16: 첫 복수 성공 |

## 설치 및 실행

### 로컬 실행

```bash
git clone https://github.com/your-org/shortform-engine.git
cd shortform-engine
pip install -r requirements.txt
streamlit run main.py
```

`.streamlit/secrets.toml` 생성:

```toml
ANTHROPIC_API_KEY = "sk-ant-..."
```

### Streamlit Cloud 배포

1. GitHub 레포 생성 후 파일 4개 업로드
2. [streamlit.io/cloud](https://streamlit.io/cloud) → New app
3. Repository 선택 → Main file: `main.py`
4. Advanced settings → Secrets:

```toml
ANTHROPIC_API_KEY = "sk-ant-..."
```

5. Deploy

## 사용 방법

### 새 숏폼 만들기

1. **막장 공식 선택** — 4종 중 택1 또는 커스텀 아이디어 입력
2. **주인공 설정** — 이름/나이/직업 + 처한 상황 (최대한 불쌍하게)
3. **악역 설정** — 이름/나이/직업 + 관객이 분노하는 행동
4. **핵심 비밀** — EP 몇 화에서 드러나는지 포함해서 2~3개
5. **시즌 질문** — 이 드라마의 핵심 질문 1줄
6. **컨셉 생성** 클릭
7. **아크 생성** 클릭 → 100화 테이블 확인
8. **블록 1~20** 순서대로 클릭 → 5화씩 대본 생성
9. **전체 TXT 다운로드**

### 기존 글 변환

1. **TAB 2** 선택
2. 원본 텍스트 붙여넣기 (최대 3,000자)
3. 변환할 막장 공식 선택
4. **숏폼으로 변환** 클릭
5. 분석 결과 + 파일럿 EP1 확인
6. 마음에 들면 **이 컨셉으로 100화 만들기** 클릭

## 버전 기록

### v2.2 (2026-11-19) — 범용 엔진으로 정리

어떤 공식을 골라도 결과가 오피스 괴롭힘극으로 모이던 문제를 고쳤습니다.

| 항목 | v2.1 | v2.2 |
|------|------|------|
| 프롬프트 예시 | 한 작품의 인물·회사·설정에 고정 | **자리표시([주인공]/[악역]…) + 공식별 예시 묶음(FORMULA_EXAMPLES)**. 고른 공식의 예시만 들어감 |
| 공식별 무대 | 회의실·회식 위주 | 재벌복수=시댁 식탁·결혼식장 / 복수극=장례식장·주주총회장 / 귀환재회=유치원 앞·공항 / 능력각성=경매장·시험장 / 감성숏폼=카페·약혼식장 |
| 작품 톤 | 조용한 악역으로 고정 | **조용한 톤 / 독한 톤 선택**. 조용한 악역 지침은 조용한 톤에서만 들어감 |
| 아크 | EP 6~15 축적 → EP 16 첫 복수 | **EP 16 이전에도 3~5화마다 작은 응징 1회**. 큰 떡밥은 과금 관문까지 유지 |
| EP1 기준 | 상황 변화·선택·클리프행어 | **EP1 전용 기준 5개**: 3초 안에 거부당하는 그림 / 15초 안에 타격 대사 / 전제 공개 / 강자의 얼굴 / 주인공의 첫 행동으로 엔딩 |
| 혼자 있는 씬 | 2씬 연속 금지 | **전체 씬의 10% 이하** (5화 블록에 최대 1개) |
| 첫 자막 | [충격/반전/사이다] 고정 | **배지형 / 문장형 / 없음 선택**. `[자막]` 줄 자체는 항상 유지 |
| 블록 기본 감정 | 블록 번호별 고정 콤보 | 아크가 화마다 정한 감정(응징 화 포함)을 먼저 사용 |

추가 수정(같은 날): 능력 각성 공식은 능력이 EP1에 나오도록 바꿨습니다. EP 16까지 감추는 것은 능력이 아니라 "그 능력의 주인이 누구인가"입니다.

바뀌지 않은 것: 컨셉·아크 JSON의 항목 이름과 구조, 대본 출력 형식(EP 줄 / `[자막]` 줄 / S# 줄 / 인물 대사 줄).
첫 자막을 '없음'으로 고르면 `[자막]` 줄만 남고 내용이 비므로, 제작 엔진에서 "훅 자막이 없는 화" 안내가 뜹니다. 정상 동작입니다.

점검 방법:

```bash
python tools/verify_patch.py                      # 프롬프트 점검 (API 키 불필요)
ANTHROPIC_API_KEY=sk-ant-... python tools/verify_patch.py --live 재벌복수 능력각성   # 실제 EP1~5 집필 점검
```
